BOOK CATALOGUE - 5 HTML PAGES

1. Keep all five .html files in the same folder.
2. Double-click index.html to open the home page in a browser.
3. Click a book title or View details to open its individual page.
4. Use Back to Home on a detail page to return to index.html.

The cover images load from Open Library when an internet connection is available.
Amazon and Flipkart buttons open live search results. Prices are indicative and may change.
